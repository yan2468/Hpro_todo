## 2. 产品设计理念与核心功能

### 2.1 产品定位

「🐮🐴的打工日志」是一款以《潜水员戴夫》（Dave the Diver）游戏内任务清单 UI 为视觉蓝本的个人效率工具。
核心场景是**日常任务管理 + 工作日报 / 周报沉淀**，并借助 AI（DeepSeek）自动聚合周报，降低复盘成本。

### 2.2 设计理念

1. **游戏化轻松视觉**：复刻游戏内清单的卡片、优先级标识、完成动效，降低「待办焦虑」，提升持续使用意愿。
2. **本地优先 + 云端同步**：桌面端基于 Electron 本地窗口运行（离线可用），数据通过自建 Fastify + PostgreSQL 后端在云端多端同步。
3. **多端覆盖**：同一套前端代码通过 Electron 产出 Windows 桌面 exe，通过 Capacitor 产出 Android apk，另含 Web 形态。
4. **AI 提效而非替代**：周报可由 DeepSeek 基于本周日报自动起草，用户仅需审阅修正；AI 配置（密钥 / 模型 / 提示词 / 生成时间）完全由用户掌控。
5. **轻提醒而非强打扰**：到点仅在屏幕右下角弹出小窗 + 电子音，支持快捷「十分钟后提醒」与自定义延期。

### 2.3 核心功能详解

#### 2.3.1 任务管理

- **层级与优先级**：支持父子任务树；四档优先级 `urgence_important`（重要且紧急）/ `urgent`（紧急）/ `important`（重要）/ `normal`（普通）。
- **拖拽交互**：同父级 + 同优先级之间可拖拽重排顺序；可拖入另一任务成为其子任务（标签等信息自动同步）；拖拽落点以虚线框模拟，过渡平滑无跳动。
- **步骤计数**：任务可含多步骤，`current`/`total` 自动计数，勾选步骤即推进进度。
- **标签与分类**：任务可绑定标签（Tags）与分类（Category），分类图标下方显示分类名。
- **提醒**：卡片 `⏰` 按钮 → 弹窗设置提醒时间（含 10/30 分钟后、1 小时后、今天 17:00、清除提醒等快捷项）；到点主进程在右下角弹窗 + 电子音。
- **离下班倒计时（工作状态）**：首页顶部按个人资料中的「上班时间 `workStart` / 下班时间 `workEnd`」（默认 09:00–18:00）计算实时倒计时（不满 1 时不显示时、不满 1 分不显示分），并随「工作状态配置」在三态间流转：
  - **正常工作日**：`离下班还有 x 时 x 分 x 秒`；
  - **临时加班**：可设当天加班结束时间（支持跨天到次日 `overtimeCrossMidnight`），切换为 `离加班结束还有 x 时 x 分 x 秒`；
  - **调休 / 休息**：隐藏倒计时，显示 `今日调休` 等自定义文案；
  - **边界处理**：到点归零显示 `已下班`；早于上班时间显示 `还没到上班时间呢~`；当天状态可多次手动切换、未来日期可预设、所有状态与文案均持久化（localStorage `dd_work_status`）并在刷新 / 重装后恢复。
- **延期**：原「延期」入口移至右下角提醒弹窗内，支持「十分钟后提醒」快捷项与自定义延期。

#### 2.3.2 日报与周报

- **日报**：增 / 删 / 改 / 查；支持单条导出与导入模板；支持克隆（`clone`）；含报告日期 `reportDate`、时间、公司、分点内容。
- **周报**：自动聚合**本周（周一 00:00 ~ 周日 23:59:59，本地时区）**范围内的日报；展示「本周日报 x/5 条」与是否满足生成条件、预计生成时间。
- **AI 自动周报（DeepSeek）**：
  - 入口：设置中心「🤖 AI 周报（DeepSeek）」分区，可配置启用开关 / API Key / 接口地址 / 模型 / 温度 / 生成时间(HH:mm) / 提示词 / Skills。
  - 前提：本周日报 **≥ 5 条** 且本周尚无周报。
  - 触发：App 内按配置的 `genTime` 每分钟轮询自动生成；也可在报告页手动点击「🤖 生成本周周报」。
  - 实现：前端组装任务 + 提示词 → 经主进程 `ai:chat` IPC（Node `fetch` 规避浏览器 CORS）→ DeepSeek → 解析标题与要点 → 落库。
  - 兼容性：`normalizeAIUrl()` 自动补全 `/v1/chat/completions` 路径；合法模型名以 `datalist` 提示（如 `deepseek-chat`、`deepseek-reasoner`、`deepseek-coder`）。

#### 2.3.3 提醒系统

- 卡片 `⏰` 设置 `reminderAt` → 主进程 `scheduleReminder` 用 `setTimeout` 调度；到点 `showReminderPopup` 在屏幕右下角弹出（`frame:false` 透明窗 + 电子音）。
- 弹窗提供「延期」按钮与「十分钟后提醒」快捷项，延期即更新 `reminderAt` 并重新调度。
- 任务完成 / 删除时自动 `cancelReminder`，避免已办任务仍弹窗。

#### 2.3.4 跨窗口 / 多端同步

- Electron 主进程 `broadcastTasksChanged()` 广播变更；各窗口经 preload `onTasksChanged` 监听，驱动桌面小组件（透明悬浮窗 `widget.tsx`）实时刷新。
- 数据层经后端 PostgreSQL 实现多端（PC / Android / Web）云同步。

#### 2.3.5 设置中心与认证

- **设置中心**：服务器地址（断网时本地兜底）、AI 周报配置、个人资料（含上班时间 `workStart` / 下班时间 `workEnd`）、「⏰ 工作状态 / 下班倒计时」面板（当天三态手动切换 + 按日期预设未来安排 + 五条文案自定义）。
- **认证**：邮箱注册 / 登录，JWT（`@fastify/jwt`）鉴权，令牌存 `localStorage`（`dd_token`）。

#### 2.3.6 桌面小组件

- `src/widget.tsx` 提供透明、置顶、可穿透点击的悬浮窗，展示精简任务清单，与主线数据同步。

    └── dave-tasks-server.zip      # 服务端部署包（最终交付物）

### 3.2 模块划分与职责

| 层级 | 目录 | 职责 | 关键技术 |
|---|---|---|---|
| 视图层 | `src/components/*` | 渲染 UI、收集用户输入、触发 store 操作 | React 函数组件 |
| 状态层 | `src/store/*` | 持有任务 / 报告内存列表，封装 CRUD 并调用 `lib/api` | React Context |
| 逻辑层 | `src/lib/*` | HTTP、AI 配置、周报计算、提醒调度、解析 | TS 纯函数 |
| 应用编排 | `src/App.tsx` | 视图路由、表单开关、拖拽重排、提醒与 AI 生成副作用 | React hooks |
| 桌面壳 | `electron/main.ts` + `preload.ts` | 窗口管理、IPC 桥接、提醒弹窗、跨窗口广播 | Electron |
| 后端 | `server/*` | 鉴权、任务 / 报告 REST API、数据持久化 | Fastify + pg + JWT |
| 部署 | `deploy/server/*` | 生产环境后端副本（pm2 / RDS） | Node + pm2 |
| 构建 | `scripts/*` + 根配置 | 构建、清理、打包、迁移 | Python + npm scripts |

### 3.3 数据流与关键链路

1. **前端 ↔ 后端（REST）**
   - `src/lib/api.ts` 封装 `fetch`，自动附加 `Authorization: Bearer <token>`。
   - 路由前缀：`/auth/*`（注册登录）、`/tasks`（任务 CRUD）、`/reports`（报告 CRUD + clone）。
   - 后端 `server/index.ts` 注册 `@fastify/cors` + `@fastify/jwt`，各路由模块独立注册。

2. **本地状态管理**
   - `taskStore` / `reportsStore` 以 Context Provider 持有内存列表；UI 操作调用 `api.*` 后刷新列表（报告页进入时自动 `refresh()` 拉取最新）。

3. **跨窗口同步**
   - 主进程 `broadcastTasksChanged()` → preload `onTasksChanged` 事件 → 各窗口（含 `widget.tsx` 小组件）监听并更新。

4. **AI 周报链路**
   - `ReportsView` / `App` 触发 `generateAndSaveWeekly()` → `lib/aiReport.ts` 组装本周日报 + 提示词
   - → 经 `electronAPI.aiChat`（主进程 `ai:chat` IPC，Node `fetch` 规避 CORS）→ DeepSeek
   - → 解析 `{title, bullets}` → 调 `api.createReport` 落库。

5. **提醒链路**
   - 卡片 `⏰` → `ReminderPicker` 设 `reminderAt` → `notifications.scheduleReminder`（主进程 `setTimeout`）
   - → 到点 `main.showReminderPopup`（右下角透明窗 + 电子音）→ 弹窗内「延期」更新 `reminderAt` 重新调度。

6. **打包链路**
   - `npm run build:electron`：`vite build` → `tsc -p electron/tsconfig.json` → 复制 `.cjs` → `electron-builder`（输出 `release-out`）
   - `python scripts/package.py`：将 `release-out/win-unpacked` 与 `deploy/server` 分别打包为 `release/*.zip`。

### 3.4 关键约定与已知坑（必读）

- **Electron 真源是 `.cjs`**：`package.json` 的 `main` 指向 `electron/dist/main.cjs`，但 `tsc` 只产出 `main.js`。`build:electron` 脚本中必须有 `cp electron/dist/main.js electron/dist/main.cjs && cp electron/dist/preload.js electron/dist/preload.cjs`，否则打包进 exe 的是旧 cjs，导致 IPC handler 缺失。
- **dist 清理陷阱**：`vite build` 前若 `dist` 已存在，其 `emptyDir` 会触发 Node `fs.rmSync` → 被 safe-delete 钩子中断。构建前须先 `python scripts/clean_build_dirs.py`（用 `os.rename` 移走旧 `dist`/`release-out`）。
- **release-out 锁死**：若 `release-out/win-unpacked` 被运行中的 exe 锁定，electron-builder 会在 packaging 阶段卡死。解法是将 `electron-builder.json` 的 `directories.output` 指向全新未锁目录（当前用 `release-out`；如遇锁，改名后重试）。
- **优先级排序**：`App.tsx` 的 `sortByPriority` 使用 `priorityOrder()` **数值权重**（urgence_important=0 … normal=3），不可用 `localeCompare` 误排；拖拽重排限制「同父级 + 同优先级」。
- **本周范围**：`lib/aiReport.ts` 的 `parseLocalDate()` 按**本地时区**解析 `reportDate`（周一 00:00 ~ 周日 23:59:59），避免 `new Date(isoString)` 的 UTC 偏移致边界日报漏算。
- **凭证安全**：`deploy/server/.env` 与根 `.env` 含密钥，**切勿提交到公开仓库**。

### 3.6 Android（APK）构建与发布

移动端通过 Capacitor 把同一套前端套上安卓原生壳，最终由 Android Gradle 打出 APK。完整分步操作见 **`deploy/APK构建指南.md`**，核心链路如下：

1. **装工具链**：安装 Android Studio（自带 JDK + SDK），在 SDK Manager 装 **Android 14 (API 34)** + Build-Tools + Platform-Tools。
2. **配环境变量**：`ANDROID_HOME` 指向 SDK 路径，并把 `platform-tools` / `cmdline-tools\latest\bin` 加入 `Path`。
3. **生成原生工程（首次）**：`npm run cap:add` → 生成 `android/` 目录（Capacitor 6 会读取 `capacitor.config.ts` 的 `appId`/`appName` 自动初始化）。
4. **同步前端**：`npm run cap:sync`（`vite build` + 复制 `dist/` 到 `android/app/src/main/assets/public/`）。之后每次改前端只需重跑此步。
5. **放开 http 明文（关键）**：在 `android/app/src/main/AndroidManifest.xml` 的 `<application>` 加 `android:usesCleartextTraffic="true"`，否则手机访问 `http://8.163.32.86:8787` 后端会一直转圈。
6. **构建 APK**：Android Studio 菜单 `Build → Build APK(s)`，产物在 `android/app/build/outputs/apk/debug/app-debug.apk`（命令行等价：`npm run apk:debug`）。
7. **安装与配置**：把 `app-debug.apk` 传到手机安装 → App 内「配置服务器」填 `http://8.163.32.86:8787` → 注册/登录即用。
8. **迭代**：代码更新后重跑 `npm run cap:sync` → 重新 Build APK 覆盖安装；`cap:sync` 不会覆盖手动改过的 `AndroidManifest.xml`，明文配置长期保留。

> 数据库联网权限（`INTERNET`）由 Capacitor 默认模板提供；`capacitor.config.ts` 的 `appName` 已设为「🐮🐴的打工日志」，若个别手机启动器对 emoji 名称渲染异常，可改 `android/app/src/main/res/values/strings.xml` 的 `app_name`。
